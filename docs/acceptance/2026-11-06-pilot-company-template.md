# SelfLedger 企业邀请试点验收模板

> 每家企业复制一份到 Git 之外的受控客户档案。填写后可能含个人信息和业务数据，不得提交 Git。Git 只更新 G4/G5 匿名汇总。

## 基本信息

| 字段 | 记录 |
| --- | --- |
| 匿名试点编号 | `PILOT-__` |
| 当前状态 | `invited / provisioned / trained / active / blocked / completed / exited` |
| 独立 Site | 受控档案记录，不在公开副本填写 |
| 精确镜像 SHA |  |
| 试点开始/结束 |  |
| 客户代表/实施负责人 | 受控档案记录 |
| 适用类型 | 贸易 / 服务 / 混合 |

## 授权和数据边界

- [ ] 已确认免费试点条款、支持渠道和退出方式。
- [ ] 已确认数据处理范围、保存期限、备份位置和跨境边界。
- [ ] 已确认案例公开默认关闭，任何公开使用均需另行选择加入。
- [ ] 原始文件只存受控私有位置，Git、工单和普通聊天中无业务正文。
- [ ] AI 当前为关闭；或已另附真实模型批准、预算和最小数据范围。

## 开通与身份

- [ ] 独立 Site、数据库、站点目录、备份前缀和备份密钥已配置。
- [ ] 命名用户按最小权限创建，临时密码首次登录强制修改。
- [ ] 账套管理员和系统管理员已完成 2FA。
- [ ] 未知 Host 被拒绝，其他企业用户无法读取本 Site。
- [ ] 中文桌面和移动端登录说明已交付并完成一次演示。

## 数据与功能验收

- [ ] 期初主数据和余额条数、金额已由客户复核。
- [ ] 一个代表月份的客户批准文件完成导入。
- [ ] 重复记录经确认后未进入凭证、过账总数和总账。
- [ ] 自动分类、人工分类、凭证草稿、批量审核和正式过账完成。
- [ ] 会计分录、总账、收支变动和原始证据可追溯且借贷平衡。
- [ ] 销售/采购/库存或项目/工时/费用/薪资代表流程完成。
- [ ] 月结检查和中文报税准备材料包完成；未宣称已自动申报。
- [ ] 查看者只能查看获准内容，不能编辑或读取受限薪资/管理数据。

## 运维、恢复与退出

- [ ] HTTPS、证书、队列、调度器和 Site 健康检查通过。
- [ ] 最新加密备份存在，清单校验通过，密钥与备份分开保存。
- [ ] 隔离恢复结果：`PASS / PENDING`，报告位置记录在受控档案。
- [ ] 镜像回滚演练结果：`PASS / PENDING`。
- [ ] 模型供应商离线演练结果：`PASS / NOT ENABLED / PENDING`。
- [ ] 加密导出、暂停、保留期和受控销毁流程已向客户说明。

## 缺陷与签署

| 严重级别 | 数量 | 处理结论 |
| --- | ---: | --- |
| P0 |  | 必须为 0 才可继续试点 |
| P1 |  | 必须为 0 才可继续试点 |
| P2 |  | 进入计划版本 |
| P3 |  | 进入体验优化排期 |

- 客户结论：`通过 / 有条件通过 / 阻塞 / 退出`
- 客户代表签署与日期：受控档案记录
- 实施负责人签署与日期：受控档案记录
- 备注：不得粘贴口令、密钥、流水正文或个人敏感信息
