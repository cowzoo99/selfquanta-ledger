# 银行回单与支付截图自动入账实施计划

1. 为文档类型校验、来源识别和三类字段解析编写失败测试；用脱敏文字夹具覆盖 8 页 PDF、微信和支付宝的结构。
2. 实现 OCR 内部服务契约与 PDF/图片提取器；验证不写磁盘、不记录正文、错误为中文。
3. 扩展导入 API 与私有附件命名，保留 CSV 兼容和哈希复验。
4. 将导入页改为中文单入口，支持自动识别、PDF/图片、预览修正和错误提示。
5. 在 Compose 中加入无公开端口的 OCR 服务，并完成静态配置检查。
6. 本地与隔离站点运行测试；再用用户提供的三份真实样本做只读预览验收。
7. 只构建一次最终镜像，备份生产站点、迁移部署、验证 10 笔预览与权限，不确认写入真实账套。

完成定义：自动化测试通过，三份真实样本预览为 10 笔且关键字段与原件一致，生产中文工作台可用，旧 CSV 导入不回归。
