# SelfLedger 3–5 家企业邀请试点操作手册

## 使用边界

本手册用于免费邀请试点，不代表已经完成公网发布、自动报税或真实模型接入。每家企业必须使用独立 Frappe Site、数据库、站点目录、备份前缀和备份密钥；禁止在同一 Site 中用多个 Company 模拟多个客户。

客户名称、联系人、手机号、邮箱、原始流水、证照、备份位置和支持记录保存在受控客户档案中，不提交 Git。Git 只保留匿名模板和汇总状态。任何口令、私钥、模型密钥、备份密钥均不得写入本文档、工单或聊天记录。

试点状态只能是：`invited`、`provisioned`、`trained`、`active`、`blocked`、`completed`、`exited`。

## 1. 邀请和授权

开通前由客户明确确认：

- 免费试点期限、支持渠道、双方联系人和退出方式；
- 数据处理范围、原始文件用途、保存期限和备份存放地区；
- 系统是记账与报税材料准备工具，申报前仍需有权人员复核；
- 客户案例、名称、截图和评价默认不得公开，另行书面选择加入才可使用；
- AI 默认关闭；启用真实模型需另行批准数据范围、供应商、预算和凭据。

缺少任一授权时，状态保持 `invited`，不得接收真实业务文件。

## 2. 独立 Site 开通

1. 使用 [独立客户 Site 开通与生命周期](tenant-provisioning.md) 的脚本和密码文件创建 Site；禁止在命令行传递密码。
2. 将匿名开通回执和精确镜像 SHA 写入受控发布记录。
3. 创建实名用户和最小角色；临时密码首次登录必须修改，账套管理员和系统管理员必须完成 2FA。
4. 验证未知 Host 被拒绝、目标 Host 只进入目标 Site，其他客户数据不可见。
5. 运行 Site 健康检查，确认 HTTPS、队列、调度器和最新加密备份状态。

任何一步失败，状态改为 `blocked`，只修复该 Site；不得热改容器或生产数据库。

## 3. 数据导入和主链路验收

客户批准后，先在受控位置保留原文件，再按顺序完成：

1. 导入期初科目、往来单位、物料、员工和余额；核对条数及金额。
2. 导入一个代表月份的银行、微信、支付宝或图片/PDF 流水。
3. 复核疑似重复；确认重复的记录不得进入草稿、过账总笔数或总账。
4. 复核自动分类，人工处理未匹配或冲突规则，再生成借贷平衡的凭证草稿。
5. 批量审核过账后核对会计分录、总账、收支变动明细和原始证据链。
6. 按客户类型完成销售、采购、库存，或项目、工时、费用、薪资的代表流程。
7. 生成月结检查和报税准备材料包；明确标记“尚未向税务机关申报”。

## 4. 一页式用户登录与使用说明

发给用户的说明只填写其专属地址和账号，不附管理员凭据：

> 1. 打开管理员提供的 SelfLedger 专属网址；如本次仍为内网试点，先导入管理员单独发送的 WireGuard 配置并连接，再打开网址。  
> 2. 输入分配给您的账号和临时密码，首次登录立即设置自己的新密码；有管理权限的用户按提示绑定 2FA。  
> 3. 日常记账进入“文件智能导入”，上传银行/微信/支付宝 CSV、PDF、JPG 或 PNG；先看识别预览，再确认导入。  
> 4. 依次处理“重复复核 → 自动分类 → 凭证草稿 → 审核过账”，不确定的账目保留待人工确认。  
> 5. 在“会计中心”查看会计分录、总账和收支变动；销售、采购、库存、项目或人事功能从统一导航进入。  
> 6. 发现数据不符时不要重复导入或自行改数据库，请记录页面、时间和凭证号后联系指定支持人员。

## 5. 企业数据退出包

仅“企业负责人”可在统一工作台顶部进入“数据管理”：

1. 点击“生成新的退出包”，等待状态变为“准备完成”。
2. 核对页面显示的数据条数、附件数、文件大小和 SHA-256 短哈希。
3. 下载 ZIP，在本地确认文件可以打开后，将其保存到加密磁盘或加密归档中。
4. 本地副本确认无误后，再点击“删除文件”清除服务器上的退出包；该操作不会删除企业业务数据。

退出包包含业务数据、会计数据、用户身份与角色、审计记录和附件，其中可能含个人信息；不得通过公开链接或普通聊天工具转发。退出包不包含登录密码、API 密钥、系统密钥或服务器路径，也不是可直接恢复数据库的备份。

## 6. 上线、支持和退出

- P0/P1 未清零前不得继续接纳新企业；P2/P3 合并进入计划版本。
- 每家企业至少完成角色、财务、业务、移动端、备份导出和退出验收。
- 试点期间至少完成一次隔离恢复、一次镜像回滚和一次模型供应商离线演练；真实结果以报告为准。
- 客户退出时先暂停目标 Site，交付经验证的加密导出，按约定保留期处理数据，再执行受控销毁；不得删除共享卷或运行 Docker 全局清理。
- 状态变为 `completed` 或 `exited` 前，由客户代表和实施负责人在受控清单上签字确认。
