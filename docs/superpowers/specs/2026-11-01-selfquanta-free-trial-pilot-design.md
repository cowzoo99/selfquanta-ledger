# SelfQuanta 一个月免费试运行设计

日期：2026-11-01

## 1. 目标

使用腾讯云面向企业新用户的一个月轻量应用服务器免费试用，让当前内账系统尽快供公司内部少量人员完成真实流程试用，同时避免在产品价值尚未验证前购买服务器、域名或 COS 资源包。

## 2. 已确认范围

- 单公司、单账套；管理员编辑，成员只读。
- 预计少量并发，不承诺面向公众或高可用服务。
- 保留现有 Frappe/ERPNext Docker Compose 架构，不迁移 CloudBase，不重写为 Serverless。
- 当前阶段不购买域名、不提交 ICP 备案、不开放公网 TCP 80/443。
- 当前阶段不进行大规模前端重做；先用真实流程收集问题，再批准一轮有边界的 UI 优化。

## 3. 免费资源边界

- 目标资源：腾讯云上海地域、Ubuntu 24.04 LTS、4 核 CPU、8 GB 内存、180 GB SSD、12 Mbps、一个月企业免费试用。
- 免费资格和库存以领取页面为准；仅领取明确显示应付金额为 0 元的实例。
- 关闭自动续费，不购买轻量云硬盘、数据库、安全增值包、域名或付费 COS 资源包。
- 试运行期不启用 COS，避免请求、流量和免费额度到期后的残留费用；只使用本地加密定时备份，并在每个使用日结束前复制到 E 盘。
- 若免费资格不存在或领取页金额不为 0 元，停止领取，不自动改为付费订单。

## 4. 安全与数据

- Web 服务只绑定 WireGuard 地址 `10.77.0.1`；公网仅保留 SSH 和 WireGuard UDP 入口。
- 整个免费试运行只使用代表性脱敏数据。当前恢复脚本只验证加密归档校验和及关键表计数；在附件内容和管理员登录恢复校验获得独立自动化测试前，不开放真实数据门。
- IP、账号、密码、私钥、WireGuard 配置、COS 凭据和账务数据不得进入 Git、聊天或验收截图。
- 服务器到期前必须完成最终加密备份、异机副本和恢复验证；验证完成前不得删除实例。

## 5. 试运行节奏

- 第 1–3 天：领取资源、部署、私网与权限验收。
- 第 4–7 天：脱敏数据试用、重启、备份和恢复演练。
- 第 8–21 天：使用代表性脱敏账单完成内部流程试用，记录流程阻塞和界面问题，不边用边做无边界改版。
- 第 21 天：决定续费、迁移或停止。
- 最迟第 27 天：完成最终备份和退出动作，为资源到期保留缓冲。

## 6. 前端后续边界

试运行只收集可复现问题，按“阻塞记账、容易误操作、信息不清、纯视觉偏好”四级记录。退出评审后只为前三类制定一次小范围前端计划，优先处理中文化、导航、导入步骤、借贷审核和手机端表格；Logo、动画、主题系统和大型图表不在首轮范围内。

## 7. 成功标准

- 免费实例未产生未批准的付费订单，自动续费关闭。
- 管理员和查看者通过 WireGuard 完成各自权限验收。
- 重启后数据和附件仍存在。
- 加密备份存在于服务器外，且隔离恢复通过。
- 形成脱敏的试运行结论和有优先级的 UI 问题清单。
- 到期前完成明确的续费、迁移或停止决定。

## 8. 非目标

- 代替所有者进行企业实名认证、验证码、付款或云资源领取确认。
- 在试运行期公开域名、开放公网 Web 或对外收费。
- 为追求永久免费而跨多个云厂商每月迁移一次。
- 在没有真实使用证据前重做全部前端。
